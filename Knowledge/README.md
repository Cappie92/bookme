# Knowledge — каноническая база знаний DeDato

Каталог `Knowledge/` — **каноническая** проектная документация: описание **существующей** системы для онбординга и безопасного масштабирования.

Каталог `docs/` по-прежнему содержит полезные материалы, но также исторические отчёты, планы, аудиты и архив. Их нельзя автоматически считать каноном, если они расходятся с runtime-кодом.

## Приоритет источников истины

1. Runtime-код
2. Тесты
3. Модели и миграции
4. Конфигурация
5. Существующая документация (`docs/`, корневые `*.md`) — только вспомогательно

`Knowledge/` описывает **как система работает сейчас**, а не целевую архитектуру.

## Уровни уверенности

| Метка | Смысл |
|-------|--------|
| **CONFIRMED** | Подтверждено runtime-кодом и/или тестом |
| **INFERRED** | Логический вывод из нескольких участков кода |
| **REPORTED** | Есть в старой документации, полной сверки с runtime нет |
| **UNKNOWN** | Надёжно установить не удалось |

Важные утверждения сопровождаются блоком **Source** (относительные пути репозитория и, по возможности, имя символа).
Предпочитать runtime-код; тест — дополнение, не единственное доказательство поведения, если доступен runtime.
