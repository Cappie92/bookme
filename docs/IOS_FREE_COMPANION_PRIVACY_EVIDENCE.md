# iOS fixed-feature privacy evidence — 1.0.1 (4)

This file records repository/runtime evidence only. It does not authorize an App Store Connect change.

## Product boundary

- Free, Paid and AlwaysFree master accounts receive the same native iOS menu, screens and operational controls.
- Active master iOS code does not request subscription/access/plan catalog, balance, payment history, promo/points or Apple transaction endpoints.
- StoreKit source remains in the repository for historical compatibility, but the native module is excluded from Expo autolinking and the active iOS route/lifecycle graph.
- Authenticated browser handoff uses a 60-second opaque one-time code. The server accepts only `schedule`, `services` or `settings`, issues a trusted `ios_app` session claim and keeps commerce routes unavailable in that session.
- The Free limit of 20 active future bookings is enforced by the backend. It is not presented as an upgrade or purchase prompt.
